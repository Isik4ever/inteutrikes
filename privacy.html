Integritetspolicy / Privacy Policy

Senast uppdaterad: 2026-10-09

Vad appen är

"Inte Utrikes" är ett verktyg som används av kanalens egen redaktion för att ladda upp kanalens egna videor till kanalens eget konto på YouTube. Verktyget erbjuds inte till andra användare.

Vilka uppgifter som hanteras

Verktyget använder OAuth-behörigheter (YouTube Data API) enbart för att ladda upp videor och läsa status på de egna uppladdningarna. Åtkomsttoken lagras lokalt på redaktionens dator och delas inte med någon tredje part.

Vad som inte görs

Inga personuppgifter om tittare eller andra användare samlas in, lagras, säljs eller delas. Ingen data används för annonsering. Inga kommentarer, följarlistor eller statistik om andra personer hämtas.

Lagring och radering

Token kan när som helst återkallas av kontoinnehavaren via YouTube/Google. Lokala filer raderas efter uppladdning.

YouTube API Services

Verktyget använder YouTube API Services för att ladda upp videor till kanalens eget YouTube-konto. Genom att använda verktyget godkänner redaktionen YouTubes användarvillkor. Googles integritetspolicy gäller för den data Google behandlar: https://policies.google.com/privacy.

Verktyget lagrar bara en OAuth-token lokalt på redaktionens dator. Ingen YouTube-data om andra användare hämtas eller lagras. Åtkomsten kan när som helst återkallas på Googles säkerhetsinställningar; då raderas den lokala token vid nästa körning. Begäran om radering av uppgifter: tristitiauf@gmail.com.

Tredje parter

Videorna publiceras på YouTube (Google), vars egen integritetspolicy gäller där.

English summary. This tool uses YouTube API Services to upload videos to the channel's own YouTube account; by using it the editor agrees to the YouTube Terms of Service, and the Google Privacy Policy applies to data processed by Google. Only an OAuth token is stored, locally; no data about other users is collected. Access can be revoked at any time at Google security settings, which deletes the stored token on the next run; deletion requests: tristitiauf@gmail.com. "Inte Utrikes" is a single-operator tool used by the channel's own editor to upload the channel's own videos to its own YouTube and TikTok accounts. It requests OAuth scopes only to upload videos and read the status of those uploads. Tokens are stored locally on the editor's computer. No personal data about viewers or other users is collected, stored, sold or shared, and no data is used for advertising. Tokens can be revoked at any time through Google or TikTok.
